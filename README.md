# J2 ナビ

サッカー J2 リーグの **試合結果・日程・順位表** を見られる Web アプリ(スマホ向け / PWA 対応)。
お気に入り登録したチームの情報をトップ画面にまとめて表示します。

## 機能

| 画面 | 内容 |
| --- | --- |
| ★ お気に入り | 登録チームごとに 順位・勝点・勝分負・得失点差・直近5試合、**次の試合**(今日/明日/◯日後)、前回の結果、今後の予定3試合 |
| 📅 日程・結果 | 節ごとの試合一覧(日付別)。前後の節に移動、「お気に入りチームのみ表示」で絞り込み |
| 🏆 順位表 | 勝点 → 得失点差 → 総得点で並べた順位表。自動昇格・プレーオフ・降格圏を色分け、お気に入りはハイライト |
| ⚽ チーム | 全チーム一覧。☆ でお気に入り登録(複数可) |

- チーム名をタップすると、そのチームの全日程・全結果をシートで表示
- お気に入りはブラウザ(localStorage)に保存
- 各クラブの**公式クラブカラー**(基調色・文字色・差し色)と**エンブレム**で表示。お気に入りカードやチーム詳細のヘッダーはクラブカラーの帯になります
- ダークモード対応

## 起動

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # 単体テスト
npm run build    # 本番ビルド (dist/)
```

## データソース

デフォルトでは **サンプルデータ**(2026/27シーズンの実際のJ2所属20クラブで自動生成した、架空の日程・結果)で動きます。
画面上部に「サンプル」と表示されます。

### クラブ情報 (`src/data/clubs.ts`)

- 所属クラブ・クラブカラー: Wikipedia 日本語版「2026/27シーズンのJ2リーグ」と各クラブ記事の infobox(Jリーグ公式プロフィール準拠)を参照
- エンブレム: [TheSportsDB](https://www.thesportsdb.com/) の画像を参照(アプリ内には同梱していません)。読み込めない場合はクラブカラーの頭文字バッジに自動で切り替わります
- エンブレム・クラブカラーの権利は各クラブに帰属します。アプリを一般公開する場合は、各クラブ・Jリーグの利用規定を確認してください

実データを使う場合は [API-Football](https://www.api-football.com/) のAPIキーを取得し、`.env.local` を作成します。

```bash
cp .env.example .env.local
# VITE_DATA_SOURCE=api-football
# VITE_API_FOOTBALL_KEY=<あなたのキー>
# VITE_SEASON=2026
```

- J2 の league id は `99`。チーム一覧と全試合を取得し、順位表は試合結果から計算します
- API の英語チーム名を `clubs.ts` と照合し、日本語名・クラブカラーで表示します(エンブレムは API のものを使用)
- 無料枠のリクエスト数節約のため、取得結果は10分間キャッシュします(⟳ ボタンで強制更新)
- 注意: `VITE_` 変数はビルド後のJSに埋め込まれるため、公開サイトにする場合はキーを隠すサーバー側プロキシを用意してください
- 無料プランでは取得できるシーズンに制限がある場合があります
